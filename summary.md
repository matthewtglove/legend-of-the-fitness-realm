# Lofr App: Product Definition

## 1. Core Concept: The JRPG Fitness Structure

_The fundamental architectural shift: Separating "Narrative" from "Gameplay."_

-   **The Overworld (Story Mode):** Occurs in the Hub, Warm-ups, and Cool-downs. Focused on plot, dialogue, and RPG management.
-   **The Battle (Workout Mode):** Occurs during the main exercise set. Focused on high-contrast, auto-play gaming loops where **Physical Effort = Game Input**.
-   **The Bridge:** The Story provides the "Skin" (Theme/Visuals) for the Battle, but the Battle mechanics remain consistent (e.g., a "Survivor" game mode can be skinned as Fantasy or Sci-Fi).

## 5. The Realm System (Architecture)

_Replacing the "Narrative Engine" with a modular "Cartridge" system._

### The "Cartridge" Concept

The app acts as a Console. Narrative Campaigns are Cartridges that dictate the **Theme**, **Music**, and **Sprites**, but they plug into standardized **Game Engines**.

### The Story Mode (Cutscenes)

-   **Role:** Context & Emotion.
-   **Timing:** Pre-workout, Warm-up, Cool-down.
-   **Format:** Audio drama + 2D Scene rendering.
-   **Injection:** Can briefly interrupt a workout (e.g., "Boss Appearing!") but does not control the minute-by-minute experience.

### The Battle Mode (Workout Engines)

-   **Role:** Focus & Effort.
-   **Timing:** The Main Set / Interval.
-   **Mechanic:** Auto-play games where user effort provides the boost.

#### Battle Engine Types:

1.  **Survivor Mode (Bullet Hell):**
    -   _Best for:_ HIIT / Intervals / Cycling.
    -   _Loop:_ Avatar shoots automatically. User speed/HR increases fire rate and clears the screen.
2.  **RPG Mode (Turn-Based):**
    -   _Best for:_ Strength / Reps.
    -   _Loop:_ User performs a set -> Avatar unleashes a combo attack. User rests -> Enemy attacks avatar.
3.  **Idle Mode (Tycoon/Builder):**
    -   _Best for:_ Steady State Cardio.
    -   _Loop:_ User consistency speeds up construction or resource mining.
